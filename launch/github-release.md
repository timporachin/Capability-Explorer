# Capability Explorer v0.1.0

A repository explanation tells you what a tool does. It often leaves the harder question unanswered: what could it add to the project you're already building?

Capability Explorer is an MIT-licensed AI skill for that second question. Give your assistant the skill and a technology to inspect. It connects supported capabilities to relevant project context already available, then explains practical and unexpected implementations and what they require.

For example: computer-use capabilities plus a desktop launcher could become tests of the handoff into third-party programs and back. That is a proposed integration, not a built-in feature or a completed test system.

This early release includes:

- Quick, Explorer, and Deep Dive views.
- Explicit VERIFIED / REPORTED / INFERRED POSSIBILITY distinctions.
- Manual usage and documentation-checked host installation instructions.
- Four short examples, behavioral acceptance scenarios, and structural validation.

It is an instruction-based skill, not a hosted app. Results depend on the assistant and evidence it can access. Host installation recipes are not end-to-end certified; behavioral scenarios are not a cross-model reliability guarantee.

[Start here](https://github.com/timporachin/Capability-Explorer#readme). Feedback is especially useful when an analysis misses a real project connection or overstates a capability.
