# Show HN draft

**Title:** Show HN: Capability Explorer – what could this repo add to your project?

**URL:** https://github.com/timporachin/Capability-Explorer

**Optional first comment:**

I built an AI skill for the question that usually comes after a repository summary: “Where could this fit into what I'm building?”

It asks the assistant to use relevant project context it already has, inspect the target, and explain a few concrete connections. One example: a computer-use agent could test whether a desktop launcher regains focus after a third-party app closes. The connection comes from the existing project boundary, not a generic list of AI ideas.

Proposed integrations are labeled as inference, separate from inspected capabilities and README claims. Resource-heavy ideas remain eligible when the payoff is worthwhile.

This is a small Markdown skill, not a service or autonomous build system. You can try it by attaching SKILL.md. Native host recipes are documentation-checked; I would appreciate reports of useful connections, misses, and claims the skill should have treated more cautiously.
