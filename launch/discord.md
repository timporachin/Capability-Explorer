# Discord/community draft

I made **Capability Explorer**, a small open-source AI skill that asks what a new repo/tool could add to the project you're already building.

Example: computer-use capabilities could help a desktop launcher test handoffs into third-party apps. It labels that as proposed integration work and explains what's missing.

Attach SKILL.md to try it. Examples and feedback guidance: https://github.com/timporachin/Capability-Explorer
